## ❓ FAQ

### Q : Par où dois-je vraiment commencer ?
**R :** README.md, puis ce guide, puis le document correspondant à votre rôle (voir sections ci-dessus).

### Q : Combien de temps pour lire toute la documentation ?
**R :** Environ 6-8 heures pour une lecture complète et approfondie. Mais vous pouvez commencer à contribuer après 1-2 heures de lecture ciblée.

### Q : La documentation sera-t-elle mise à jour ?
**R :** Oui ! Chaque document a une date de dernière mise à jour. La documentation évoluera avec le projet.

### Q : Je ne trouve pas l'information que je cherche
**R :** Utilisez la recherche (Ctrl+F) dans les fichiers Markdown. Si toujours introuvable, ouvrez une issue GitHub.

### Q : Puis-je contribuer à la documentation ?
**R :** Absolument ! Voir [CONTRIBUTING.md](../CONTRIBUTING.md) pour les guidelines.
