## 1. Positionnement et Messaging

### Positionnement Marché

**Pyralys = "Votre assistant IA créatif pour les réseaux sociaux"**

**Positionnement unique :**
- ❌ **Pas un outil d'automatisation pure** (Hootsuite, Buffer) → trop basique, pas d'IA
- ❌ **Pas un générateur AI générique** (ChatGPT, Jasper) → pas spécialisé social media
- ✅ **Assistant créatif intelligent** qui combine génération IA + publication + analytics dans un workflow unifié

**Value Propositions par Segment :**

#### Pour PME / E-commerce
```
"Passez de 10h/semaine à 2h/semaine sur vos réseaux sociaux,
sans sacrifier la qualité ni l'engagement"

Bénéfices clés :
- Économie de temps : 80%
- Économie d'argent : Plus besoin de freelance à 500€/semaine
- Résultats mesurables : +35% engagement moyen
```

#### Pour Créateurs de Contenu
```
"Multipliez votre production de contenu par 3,
gardez votre authenticité"

Bénéfices clés :
- Combattre le burnout créatif
- Réutilisation intelligente cross-plateformes
- Analytics pour identifier ce qui marche vraiment
```

#### Pour Agences Marketing
```
"Gérez 2x plus de clients avec la même équipe
grâce à l'automatisation IA"

Bénéfices clés :
- Scalabilité sans embauche
- Templates personnalisables par client
- Reporting automatisé
```

**Tagline Principal :**

**Headline Homepage :**

### Churn Prevention

**Indicators de Churn Potentiel :**
- Pas de connexion depuis 7 jours
- Pas de post créé depuis 14 jours
- Downgrade intention (visite page pricing)
- Feedback négatif (NPS < 6)

**Actions Automatiques :**

**Si inactif 7 jours :**
```
Email: "We miss you, [Name]"

Hey [Name],

Haven't seen you in a week. Everything okay?

Is there anything we can help with?

P.S. We just added [new feature] that I think you'll love.

[CTA: Check It Out]
```

**Si inactif 14 jours :**
```
Email: "Special offer just for you"

[Name], we noticed you haven't been using Pyralys much lately.

Here's a one-time offer: 50% off for 3 months if you come back.

[CTA: Claim Offer] (expires in 48h)
```

**Si intention downgrade/cancel :**
- Trigger modal : "Wait! Before you go..."
- Offrir alternatives :
  - Pause subscription (1-3 mois)
  - Downgrade to cheaper plan
  - Talk to us (what can we fix?)
