## Risques et Mitigations

### Risque Technique
**Problème :** Accès API TikTok refusé (limited access program)
**Mitigation :** Lancer sans TikTok, ajouter en Phase 2 si accès obtenu. Focus Instagram + Facebook pour MVP.

### Risque Marché
**Problème :** Concurrence agressive (ex: Buffer lance feature IA)
**Mitigation :** Différenciation par qualité IA + UX supérieure. Vitesse d'exécution critique.

### Risque Financier
**Problème :** CAC trop élevé vs LTV
**Mitigation :** Focus organic growth (SEO, Product Hunt, community). Paid ads seulement si ROI >3x.

### Risque Opérationnel
**Problème :** Turnover équipe développement
**Mitigation :** Documentation exhaustive. Code reviews. Knowledge sharing sessions.
